# skills

项目中常用的提示词和 Codex Skills。

## 当前内容

- [business-logic-documenter](./business-logic-documenter/)：梳理前端、后端、SQL、数据库定时任务、触发器、消息和外部系统等数据来源，生成可维护的业务逻辑文档。

## 使用方式

在 Codex 中安装或引用本仓库中的 Skill，调用：

`$business-logic-documenter`

如果不使用 Skill，也可以直接复制 [business-logic-documenter/prompt.md](./business-logic-documenter/prompt.md) 作为提示词。
